## Air-side instructions

1. Copy the single ZIP to MacBook Air over a trusted private method.
2. Extract it normally and open `YuTool-First-User-Mac/`.
3. Read `README-FIRST.zh-CN.md`.
4. In Terminal, from that directory execute:

```bash
bash First-User-Test.command --verify-only
bash First-User-Test.command --run
```

If the user is unfamiliar with Terminal's working-directory operation,
drag `First-User-Test.command` into the Terminal command line
and prefix the resulting path with `bash `, then append either
` --verify-only` or ` --run`.

No developer Python, Cargo, Node, Rust or Xcode installation is required
for this kit. It uses macOS' native tools, and the original CLI ZIP
already bundles its own required engine runtime.

Each run prints an independent temporary directory path such as
`.../yu-first-user-XXXXXXXX/`, holding `report.tsv` and logs.
If command execution is blocked by macOS, record the original message
and report FAIL/BLOCKED. Do not run global security bypass commands.
