## Test and safety boundaries

The private preview is an **ordinary command-line tool**, not an
Electron/Tauri desktop UI or installer. Included built-in image
features and PSD inspect/tree/layer read/export were already validated
in source-bound GitHub Actions, with **20/20 isolated CLI steps** for
each platform. In addition, the **newly wrapped macOS platform ZIP**
was unpacked again and run through the same 20-step isolation test
against the exact unchanged engine ZIP: **20/20 PASS**, fresh
HOME/YU_DATA_HOME and no development PATH.

Windows and Linux outer ZIPs passed full archive and hash verification,
and their unchanged *inner* binaries/engines have the exact previous
20/20 CI acceptance hashes. We did **not** independently execute the
newly wrapped Windows or Linux ZIPs on physical test machines.

The test policy is deliberately narrow:

- No public `v0.1.0` tag, GitHub Release, unaudited upload or official
  mirror was created.
- No Apple notarization was submitted. Current original Mac CLI
  developer archive must **not be advertised as a Developer ID signed
  notarized end-user app**. macOS Gatekeeper may block it.
- Windows is an **unsigned development preview**, potentially
  triggering Microsoft Defender SmartScreen/reputation prompts.
  Do not ask testers to disable security protection globally.
- On Windows, external holders may prevent Managed engine removal:
  **Issue #27 known-risk policy B**. The bounded operation fails
  safely and preserves the original installed version; after a
  holder releases the file, a test operator may retry.
- Tested output operations should use throwaway *copies* of images;
  the current product has **no PSD writer or layer rename command**.
- Manual install/use only; no updater, minimum supported OS
  certification for all three platforms, or ordinary consumer support
  guarantee.

## Repeatable private staging procedure

The sources must be the six already verified exact-main candidate/
Managed Engine ZIPs and their original source metadata/CI
acceptance receipts, all within an isolated, non-public directory.
The existing **offline source audit** runs before re-bundling:

```text
python3 -B tools/build_v01_dev_private_preview.py \
  --artifacts-dir <original-exact-main-evidence-folder> \
  --destination <new-empty-private-output-folder>

python3 -B tools/build_v01_dev_private_preview.py \
  --verify-only --destination <private-output-folder>

python3 -B -m unittest discover -s tools -p 'test_*.py' -q
```

The builder rejects an existing destination and preserves the
byte-for-byte original CLI/engine ZIPs. Its tests also reject source
archive mismatch, output conflict, tampered platform ZIP and false
public release authorization.
