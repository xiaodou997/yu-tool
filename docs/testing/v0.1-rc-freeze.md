# v0.1 RC Freeze acceptance

This checklist validates the final release-candidate source and evidence. It does not itself authorize public release.

## Source identity

- [ ] RC Freeze PR is squash merged.
- [ ] Record the resulting exact `main` SHA.
- [ ] No later code/package/workflow commit is included without restarting this checklist.
- [ ] PR synthetic-merge artifacts are not substituted for the exact-`main` artifacts.

## Exact-main automated evidence

### CI

- [ ] push-triggered CI belongs to the frozen exact `main` SHA.
- [ ] Rustfmt passes.
- [ ] candidate/archive/distribution Python tool tests pass.
- [ ] Ubuntu check / Clippy / workspace tests pass.
- [ ] macOS check / Clippy / workspace tests pass.
- [ ] Windows check / Clippy / workspace tests pass.

### Managed Package

- [ ] push-triggered Managed Package belongs to the frozen exact `main` SHA.
- [ ] Linux x86_64 package job passes.
- [ ] macOS arm64 package job passes.
- [ ] Windows x86_64 package job passes.
- [ ] all three developer candidates use layout v2 and bind source/target/hashes.
- [ ] all three extracted candidates pass PSD + ten-cycle lifecycle acceptance.
- [ ] all three isolated acceptances execute all 20 expected CLI steps.
- [ ] source inputs remain unchanged and no-clobber/removal assertions pass.
- [ ] prototype three-target engine manifest assembles successfully.

### Windows lifecycle

- [ ] push-triggered Windows Lifecycle Diagnostics belongs to the frozen exact `main` SHA.
- [ ] resource attribution calibration passes.
- [ ] exact-directory sampling calibration passes.
- [ ] remove-window sampling calibration passes.
- [ ] regular-file singleton-witness calibration passes.
- [ ] bounded transport / creation-time Job controls pass.
- [ ] three diagnostic transport + managed repetitions pass.
- [ ] no failed-case retry is used.

## Freeze invariants

- [ ] `redistribution_review_accepted=false`.
- [ ] `public_release_ready=false`.
- [ ] Issue #27 remains open unless separately resolved with evidence.
- [ ] no Release/tag/public upload is created by this checklist.
- [ ] no timeout/retry/concurrency relaxation is introduced to obtain a green result.

## Manual gates

The owner must explicitly record a decision for each item before v0.1 publication:

- [ ] project license selected and committed;
- [ ] third-party redistribution/notices review accepted;
- [ ] Issue #27 resolved or known-risk Windows release policy explicitly accepted;
- [ ] macOS signing/notarization policy accepted and validated;
- [ ] Windows signing policy accepted and validated;
- [ ] supported OS floors defined and clean-machine acceptance completed;
- [ ] durable release hosting / trusted manifest policy accepted;
- [ ] final `v0.1.0` tag and public publication explicitly authorized.
